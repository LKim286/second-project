# ОС эффективности

Интерактивный playbook для российской ИТ-компании, которая ставит целью мировое лидерство — не «крупнейшую компанию домашнего рынка».

Внутри:

- формула эффективности (ценность / редкие ресурсы, а не загрузка людей);
- 5 управляющих контуров: рынок, поставка, талант, капитал, трение;
- 24 метрики с порогами на 12 месяцев / 3 года / 5 лет и красными флагами;
- board-страница из 12 чисел;
- 10 культурных правил с наблюдаемым поведением;
- каденция, антипаттерны, диагностика на 20 вопросов, план на 90 дней.

Пороги ориентированы на продуктовую B2B/SaaS-модель. Сервисы и marketplace используют ту же дисциплину контуров, но другие формулы маржи и North Star.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://127.0.0.1:43145](http://127.0.0.1:43145). Dev-сервер слушает `0.0.0.0:43145`, чтобы Preview и прокси могли достучаться до приложения.

## Сборка

```bash
npm run build
npm start
```
