# ОС эффективности

Интерактивный playbook для российской ИТ-компании с целью мирового лидерства: метрики, цели, культура, диагностика.

## Открыть у себя на компьютере

Нужен [Node.js 20 или новее](https://nodejs.org/). Проверка в терминале:

```bash
node -v
```

Должно быть `v20` или выше. Если команды нет — установите LTS с nodejs.org и откройте терминал заново.

Затем в папке проекта:

```bash
npm install
npm run dev
```

В браузере откройте [http://127.0.0.1:43145](http://127.0.0.1:43145).

Остановка сервера: `Ctrl+C` в том же терминале.

Windows: лучше PowerShell или «Терминал», не старый cmd. Если `npm` не находится после установки Node — перезапустите компьютер и повторите.

## Что внутри

- формула эффективности (ценность / редкие ресурсы, а не загрузка людей);
- 5 контуров: рынок, поставка, талант, капитал, трение;
- 24 метрики с порогами на 12 месяцев / 3 года / 5 лет;
- board-страница из 12 чисел;
- 10 культурных правил;
- каденция, антипаттерны, диагностика, план на 90 дней.

Пороги ориентированы на продуктовую B2B/SaaS-модель.

## Сборка

```bash
npm run build
npm start
```
