# ОС эффективности — ИТ ритейла

Playbook для внутреннего ИТ-подразделения розничной компании (~6500 человек). Это сервис, не P&L: цели не про выручку, а про скорость изменений, устойчивость пика и стоимость сервиса на уровне глобального ритейл-tech.

Внутри:

- формула эффективности сервисного ИТ;
- 5 контуров: исход для бизнеса, поставка, талант, стоимость сервиса, трение;
- 12 штабных метрик с порогами 12 месяцев / 3 года / 5 лет;
- дорожная карта;
- система вознаграждения (квартальная формула 45/35/20, запреты);
- культура, каденция, антипаттерны, диагностика, план на 90 дней.

## Открыть у себя на компьютере

Нужен [Node.js 20+](https://nodejs.org/). На Mac после установки Homebrew сначала добавьте его в PATH:

```bash
eval "$(/opt/homebrew/bin/brew shellenv zsh)"
brew install node
```

Затем в папке проекта:

```bash
git clone https://github.com/LKim286/second-project.git
cd second-project
npm install
npm run dev
```

Сайт: [http://127.0.0.1:43145](http://127.0.0.1:43145).

Новый терминал после `brew install` должен видеть `npm`. Если нет — снова выполните `eval "$(/opt/homebrew/bin/brew shellenv zsh)"`.
